# guilhermesalviano.github.io

Personal portfolio site for Guilherme Salviano, built with Next.js (App Router).

- Home, Projects, and About pages
- Static export (`output: 'export'`)
- SEO: sitemap, robots.txt, JSON-LD schema, dynamic OG images
- Vercel Speed Insights / Web Analytics
- Tailwind v4, Geist font

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
